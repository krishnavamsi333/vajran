# Vajran

Robotics Power Distribution & Monitoring Controller

## Overview

Vajran is a protected power distribution and monitoring controller
designed for mobile robots and other embedded robotic platforms.

The project focuses on power distribution, electrical protection,
current and voltage monitoring, and system-level diagnostics.

## Intended Applications

- Mobile robots
- Autonomous robotic platforms
- Distributed actuator systems
- Embedded power management
- Battery-powered machines

## Planned Features

- STM32 microcontroller
- Battery power input
- Protected power distribution
- Multiple switched power outputs
- Voltage monitoring
- Current monitoring
- Temperature monitoring
- Overcurrent protection
- Undervoltage monitoring
- CAN communication
- Status and diagnostic indicators

## Hardware

The PCB is designed using KiCad.
